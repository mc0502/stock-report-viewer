About & methodology

Honesty first. This site shows what the pipeline computes and what the backtest says it's worth — including where it fails.

Two scoring regimes

AssetScore shownMeaning
StocksEquity InvScore (0–100)The pipeline's composite. Descriptive only — backtest IC is ≈ −0.05 and the score is inversely calibrated at the top end.
ETFsPrice-based metrics12-1 momentum, trend vs 200d MA, drawdown, vol, naive Sharpe — from 2y of daily prices.
CryptoPrice-based metrics EXPERIMENTAL Same metrics as ETFs; the framework wasn't built for crypto.

Why the InvScore is descriptive, not predictive

  • Composite IC ≈ −0.053 (ICIR −0.22, p≈0.10) — indistinguishable from zero, negative in point estimate.
  • Calibration curve inverts: InvScore 60–80 buckets had negative mean 20-day returns (−5.5%, −15.4%).
  • PBO ≈ 1.4% — the weak result is not an overfit artifact; the signal is genuinely flat-to-negative.
  • The L1+12-1 momentum hybrid did not generalise out-of-sample (see the repo's RETRACTIONS record).

How to regenerate the data

Stocks come from app/signal_log.csv; ETFs/crypto are fetched live:

.venv-audit/bin/python scripts/build_site_data.py   # fetch + compute -> site/data.json
.venv-audit/bin/python scripts/build_site.py        # render the static site
Static, self-contained, no server. All numbers from a real pipeline run. Stocks use the equity InvScore; ETFs & crypto use transparent price-based metrics (methodology). Descriptive only — not investment advice.
